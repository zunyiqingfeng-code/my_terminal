# 整理桌面命令 (Claude风格)

提供一键式桌面整理功能，支持多种整理模式和选项。

## 命令语法
```
/clean-desktop [选项] [目标目录]
```

## 可用选项
- `--quick` 或 `-q`: 快速整理模式
- `--deep` 或 `-d`: 深度整理模式
- `--dry-run` 或 `-n`: 试运行，不实际移动文件
- `--backup` 或 `-b`: 创建备份
- `--rules` 或 `-r`: 指定自定义规则文件
- `--help` 或 `-h`: 显示帮助信息

## 工作流程

### 步骤1：参数解析和验证
1. 解析命令行参数
2. 验证目标目录是否存在
3. 加载自定义规则（如果提供）

### 步骤2：用户确认
显示整理计划摘要：
```
整理计划：
- 目标目录: ~/Desktop
- 模式: 快速整理
- 预计处理文件: 约XX个
- 将创建文件夹: 文档、代码、图片等
- 备份: 已启用

确定要开始整理吗？(y/n)
```

### 步骤3：调用代理执行
使用代理工具调用桌面管理代理：
```python
agent_params = {
    "task": "organize-desktop",
    "target": target_dir,
    "mode": mode,
    "options": {
        "create_backup": backup_enabled,
        "dry_run": dry_run
    }
}

result = invoke_agent("desktop-manager-claude-style", agent_params)
```

展示整理结果：

### 步骤5：提供后续选项
```

1. 查看详细报告
2. 撤销最近一次整理
3. 设置自动整理计划
4. 自定义分类规则
5. 退出

请选择 (1-5):
```

## 示例用法

### 示例1：快速整理当前目录
```
/clean-desktop --quick
```

### 示例2：深度整理指定目录（试运行）
```
/clean-desktop --deep --dry-run ~/Downloads
```

### 示例3：使用自定义规则整理
```
/clean-desktop --rules my_rules.yaml ~/Desktop
```

## 自定义规则文件格式

```yaml
# my_rules.yaml
categories:
  学术文档:
    extensions: [.pdf, .doc, .docx, .ppt, .pptx]
    folder: "学术"
    
  项目代码:
    extensions: [.py, .js, .java, .cpp, .go]
    folder: "项目"
    
  设计资源:
    extensions: [.psd, .ai, .fig, .sketch]
    folder: "设计"
    
  媒体文件:
    extensions: [.mp4, .mp3, .wav, .mov]
    folder: "媒体"

options:
  create_backup: true
  skip_hidden: true
  max_file_size: "100MB"
```

## 错误处理

### 常见错误及处理
1. **目录不存在**: 提示用户并退出
2. **权限不足**: 建议以管理员身份运行
3. **磁盘空间不足**: 提供清理建议
4. **规则文件错误**: 使用默认规则并提示

### 恢复机制
- 自动创建操作日志
- 支持撤销最近一次操作
- 提供备份恢复功能

## 性能优化

### 快速模式特点
- 仅处理顶层文件
- 跳过大文件（>100MB）
- 使用缓存加速扫描

### 深度模式特点
- 递归处理所有子目录
- 完整文件大小统计
- 重复文件检测

## 集成功能

### 与系统集成
- 支持Windows、macOS、Linux
- 集成到文件管理器右键菜单
- 支持计划任务自动运行

### 与云服务集成
- 同步整理规则到云端
- 备份重要文件到云存储
- 多设备同步整理状态

## 使用建议

### 最佳实践
1. **定期整理**: 建议每周运行一次
2. **先试运行**: 首次使用前先试运行
3. **备份重要文件**: 整理前备份关键文件
4. **自定义规则**: 根据工作习惯调整规则

### 高级技巧
1. **排除特定文件**: 在规则中添加排除列表
2. **智能分类**: 基于内容而不仅是扩展名
3. **自动化计划**: 设置定时自动整理
4. **跨设备同步**: 在多台设备间同步整理规则
